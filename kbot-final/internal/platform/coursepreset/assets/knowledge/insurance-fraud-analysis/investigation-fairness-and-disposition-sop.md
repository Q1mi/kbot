# 反欺诈调查、公平性与处置 SOP

| 字段 | 内容 |
| --- | --- |
| 文档编号 | IN-FR-002 |
| 版本 | 2026.08 |
| 适用范围 | 高风险理赔案件的支付冻结、调查立案与结案建议 |
| 责任角色 | 反欺诈分析人员、调查人员、理赔审批人、合规人员 |

## 1. 前置条件

支付冻结要求：

- 案件状态为 `assessing`；
- 风险分达到或超过 `0.70`；
- 已记录规则集和主要信号；
- 冻结原因包含可复核的业务事实；
- 获得授权人员审批。

课程业务系统在冻结成功后将案件转为 `suspected_fraud`。调查立案应基于已冻结或经人工确认的高风险案件。

## 2. 两阶段受控动作

### 阶段一：支付冻结

1. 重新读取案件与风险特征，防止使用过期状态；
2. 生成冻结理由和稳定幂等键；
3. 展示风险分、阈值、规则集、主要信号和影响；
4. 等待人工审批；
5. 执行后记录冻结操作 ID 和最新案件状态。

推荐幂等键：`hold:{claim_id}:{rule_set}:{risk_score_basis_points}`。

### 阶段二：调查立案

1. 确认案件处于 `suspected_fraud`；
2. 为每个信号定义调查问题和证据需求；
3. 排除与保险风险无关的敏感属性；
4. 生成调查范围、优先级和责任人；
5. 通过独立审批后创建调查任务。

推荐幂等键：`investigation:{claim_id}:{rule_set}:{scope_version}`。

## 3. 调查计划模板

调查计划包含：

- 案件事实时间线；
- 保险责任与理由码；
- 风险分、阈值和规则集；
- 信号与现有证据映射；
- 待核验假设；
- 需要调取的材料与合法来源；
- 调查责任人、截止时间和升级路径；
- 对客户权益的影响及控制措施。

## 4. 公平性控制

- 使用与合同责任、事故真实性和材料一致性直接相关的特征；
- 对同类事实采用一致阈值和流程；
- 为每项高风险结论保留可解释证据；
- 为数据错误、时区问题和合法重复材料保留纠正渠道；
- 最终拒赔、追偿或欺诈认定由具备权限的人员决定。

## 5. 处置边界

Agent 可以生成分流建议、冻结参数和调查计划。最终处置需要同时参考：

1. 确定性保险责任结果；
2. 调查获得的有效证据；
3. 适用规则与合规要求；
4. 授权人员的审核决定。

高风险分数不直接触发拒赔或欺诈认定。

## 6. 异常处理

以下情况停止写操作并转人工：

- 案件状态不允许冻结；
- 风险分、阈值或规则集缺失；
- 信号证据相互矛盾；
- 涉及受保护属性或来源不明数据；
- 冻结结果未知；
- 已存在相同调查任务；
- 客户申诉或监管时限需要立即处理。

## 7. 审计记录

分别记录冻结和调查的输入、幂等键、审批人、执行结果、证据来源、责任人、时间线、客户通知状态和最终处置依据。
