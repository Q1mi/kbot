# 跨境结算差异对账与申诉规范

| 字段 | 内容 |
| --- | --- |
| 文档编号 | CB-SC-002 |
| 版本 | 2026.08 |
| 适用范围 | 平台结算单差异识别、复核和申诉立案 |
| 责任角色 | 供应链财务、跨境结算专员、审批人 |

## 1. 基础计算

结算差异使用确定性算式：

`difference = expected_amount - paid_amount`

计算时保留账单原币种，金额精度遵循账单返回值。禁止在同一算式中混用不同币种。

- `difference > 0`：实结金额低于应结金额，可进入申诉评估；
- `difference = 0`：金额一致，记录核验结果；
- `difference < 0`：实结金额高于应结金额，交财务人员核查是否存在多付或口径差异。

## 2. 申诉前置条件

自动准备申诉材料需要满足：

1. 账单状态为 `difference_detected`；
2. 应结金额与实结金额齐全；
3. 两个金额币种一致；
4. 差异大于零；
5. 差异来源能够关联到费用项目、订单或规则依据；
6. 当前账单没有重复立案记录。

## 3. 证据包

申诉证据包至少包含：

- 账单号、结算周期和平台；
- 应结金额、实结金额、币种和差异算式；
- 差异费用项及平台规则版本；
- 关联订单、物流或退款凭证；
- 查询时间、工具返回版本和经办人；
- 期望处理结果。

事实与解释应分开呈现。未知费用项标记为“待平台核验”，避免生成未经证实的扣费原因。

## 4. 课程基准案例

账单 `STMT-2026-31`：

- 应结金额 `118.47 USD`；
- 实结金额 `106.95 USD`；
- 状态 `difference_detected`；
- 差异 `118.47 - 106.95 = 11.52 USD`。

该案例满足差异金额条件。立案前仍需确认费用项目、证据附件和重复申诉状态。

## 5. 幂等与审批

推荐幂等键：`reconciliation:{statement_id}:{difference_minor}:{currency}`。

申诉创建属于对外写操作，必须由财务审批人确认账单、差异金额和证据完整性。相同账单和金额重试时复用幂等键。

## 6. 终止与转人工条件

- 账单状态不允许申诉；
- 金额、币种或规则版本缺失；
- 差异小于等于零；
- 费用项目无法追溯；
- 已存在申诉案件；
- 工具结果相互矛盾或执行状态未知。

## 7. 审计要求

记录代入算式、证据清单、缺失项、申诉理由、审批状态、幂等键、申诉案件 ID 和最终处理结果。
