# 跨境商品履约诊断指南

| 字段 | 内容 |
| --- | --- |
| 文档编号 | CB-PO-001 |
| 版本 | 2026.08 |
| 适用范围 | 美国站跨境订单的商品运营与履约诊断 |
| 数据性质 | 课程业务规则；实时订单、库存和物流结果以业务工具为准 |

## 1. 核心术语

- `awaiting_shipment`：订单已支付并等待发货，可继续评估履约恢复或取消退款。
- `partially_shipped`：部分商品已发出，须按商品明细区分已履约与待履约数量。
- `cancelled`：订单已取消，不再创建调拨或重复退款。
- `available`：当前可用于新履约动作的库存数量。
- `reserved`：已被其他订单或流程占用的库存，不能计入可调拨量。
- `ship_by`：平台承诺的最晚发货时间。
- `sla_eligible`：物流渠道能否满足当前订单时效约束的确定性结果。

## 2. 诊断所需事实

每次诊断至少核验以下事实，并在结论中记录来源：

1. 订单号、市场、币种、状态、实付金额与取消窗口；
2. SKU、待履约数量、原履约仓和 `ship_by`；
3. 各候选仓的 `available` 与 `reserved`；
4. 候选物流渠道的费用、预计天数和 `sla_eligible`；
5. 查询时间及工具返回的业务版本信息。

涉及广告、流量、商品标题、竞品价格、转化率或毛利时，当前履约工具无法提供完整事实。输出中应列出数据缺口，并交由商品运营人员补充。

## 3. 履约方案评估顺序

### 3.1 保留原仓履约

当原仓 `available >= 待履约数量`，且存在满足 SLA 的物流渠道时，可保留原履约方案。需要同时展示渠道费用和预计时效。

### 3.2 切换物流渠道

原渠道无法满足 SLA，且同一履约仓存在 `sla_eligible=true` 的替代渠道时，可提出渠道切换建议。建议包含：

- 原渠道与候选渠道；
- 预计时效差异；
- 运费差异；
- 对平台履约承诺和买家体验的影响。

### 3.3 跨仓恢复

原仓缺货，其他仓 `available >= 待履约数量` 时，可生成跨仓方案。调拨前必须确认：

- 源仓与目标仓不同；
- 调拨数量大于零且不超过源仓 `available`；
- 目标市场和物流时效仍可满足订单要求；
- 写操作使用稳定幂等键并进入人工审批。

### 3.4 取消退款

履约恢复不可行、买家取消窗口仍开放且订单处于 `awaiting_shipment` 时，可准备退款方案。退款金额应大于零，且不得超过订单实付金额。

## 4. 课程基准案例

订单 `TTS-20260801-1001` 的关键事实：

- 美国市场，订单金额 `129.99 USD`；
- 状态 `awaiting_shipment`，取消窗口开放；
- SKU `SKU-BLACK-M-01`，待履约数量 1；
- 原仓 `WH-CN-SZ` 可用库存 0；
- `WH-US-LAX` 可用库存 18；
- 4PX US Priority：`12.80 USD`、预计 7 天、满足 SLA；
- UPS Ground：`9.40 USD`、预计 4 天、满足 SLA。

该案例应优先比较美国仓直接履约与跨仓恢复的可执行路径，并将库存、时效和成本依据分别列出。任何调拨或退款动作都需要独立审批。

## 5. 转人工条件

- 订单状态不在允许处理范围；
- SKU、市场、币种、实付金额或履约仓缺失；
- 库存与订单明细发生冲突；
- 所有物流渠道均无法满足 SLA；
- 工具结果超时、版本缺失或相互矛盾；
- 需要使用当前工具集未覆盖的营销或利润数据。

## 6. 审计记录

诊断结果应保存订单号、SKU、事实快照、查询时间、候选方案、选定理由、未选理由、审批状态、幂等键和最终执行结果。金额保留原币种，时间统一携带时区。
